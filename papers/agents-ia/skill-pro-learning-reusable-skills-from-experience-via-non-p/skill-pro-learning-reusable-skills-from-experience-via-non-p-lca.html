Skill-Pro: Learning Reusable Skills from Experience via Non-Parametric PPO for LLM Agents

Lecture Critique d'Article

Objectif et contexte

Skill-Pro s'attaque au défaut central des agents LLM en prise de décision séquentielle : ils re-dérivent les mêmes solutions à chaque épisode, même quand la situation se répète. Les auteurs distinguent mémoire épisodique (trajectoires brutes, réflexions distillées, graphes) et mémoire procédurale, inspirée de la cognition humaine, qui mappe directement une situation à une séquence d'actions. La promesse : capitaliser l'expérience sans fine-tuner le modèle, en construisant un pool de skills exécutables réutilisables.

Trois obstacles sont identifiés explicitement : exécutabilité (transformer des récits passifs en procédures activables), réutilisabilité fiable (garantir un gain de performance constant), optimisation non-paramétrique (apprendre sans dégrader les capacités générales du LLM). Le cadrage conceptuel est précis et le problème, réel.

Méthodologie

Le cœur du papier formalise un Skill-MDP où la politique se factorise en politique de sélection de skill μ et politique d'action LLM π_LLM. Un skill est un triplet ⟨activation, procédure, terminaison⟩ exprimé en langage naturel. L'apprentissage porte exclusivement sur l'évolution du pool Ω, le LLM et μ restant figés.

L'innovation principale réside dans la Non-Parametric PPO, qui transpose les ingrédients de PPO au niveau sémantique :

  • Gradients sémantiques : pour chaque trajectoire où un skill est invoqué, un LLM produit par attribution rétrospective un triplet (g_I, g_π, g_β) de directions de raffinement en langage naturel, agrégées au niveau du batch.
  • PPO Gate : vérification trust-region calculée sur les trajectoires historiques. Le ratio d'importance ρ_t = π_LLM(a_t|s_t,ω')/π_LLM(a_t|s_t,ω) et l'avantage estimé par return-to-go avec baseline mobile sont combinés dans un objectif clippé. Seul le candidat avec J(ω') > 0 entre dans le pool.
  • Score en ligne : gain advantage-style accumulé sur les pas où le skill est actif, normalisé par le nombre d'invocations, pour pruner les skills sous-performants ou redondants.

L'évaluation utilise ALFWorld (Train + OOD) et Mastermind-v0 de TextArena (Base, Hard, Extreme). Les baselines couvrent l'ensemble du spectre mémoire-augmentée : RAG, Expel, A-MEM, AWM, G-Memory, plus ReAct, CoT, et un agent State-only. Les évaluations cross-agent utilisent Gemma-2-9B pour apprendre puis Gemma-3-4B, Qwen3-32B, LLaMA-3.3-70B pour réutiliser. Sur ALFWorld, Qwen3-32B partout. Tous les baselines partagent le même LLM gelé, ce qui isole correctement la contribution de la mémoire.

Résultats principaux

Les chiffres sont nets. En réutilisation in-domain sur Mastermind-v0, Skill-Pro atteint 0,925 contre 0,349 pour RAG, 0,285 pour Expel, 0,020 pour A-MEM. La compression mémoire est l'argument le plus frappant : 816 tokens stockés au total contre 116 527 pour RAG et 391 706 pour AWM, soit deux ordres de grandeur. Le Δ prompt tokens par étape (273) reste inférieur à RAG (2698) tout en gardant une retrieval ratio modérée (0,591).

Côté performance, Skill-Pro domine sur ALFWorld OOD (0,909 vs 0,900 pour AWM) et sur Mastermind-v0 (0,606 vs 0,577 pour G-Memory). Les gains se maintiennent en cross-agent : Qwen3-32B atteint 0,615 avec les skills appris par Gemma-2-9B, contre 0,497 en State-only.

L'ablation est la partie la plus convaincante. Retirer les skills fait chuter la performance de 0,606 à 0,388. Retirer la NP-PPO (skills figés) chute à 0,482. Sans gradients sémantiques, le PPO Gate Pass Rate s'effondre de 30 points (59,49 % → 41,54 %), confirmant que les gradients produisent des candidats de meilleure qualité. Sans PPO Gate, tous les candidats passent (100 %) mais l'instabilité visible sur les courbes d'entraînement (Fig. 3) dégrade la performance. Le remplacement du score par FIFO produit la pire dégradation (Online Score négatif de −0,0064), démontrant que le maintien actif du pool est essentiel.

Discussion et limites

Le papier souffre de plusieurs angles morts. Couverture expérimentale étroite : seulement deux benchmarks, dont un (Mastermind) est un jeu combinatoire fermé où la procédure optimale est intrinsèquement compressible. Rien ne garantit que le résultat se transpose à des environnements ouverts type WebArena ou SWE-Bench, où les patterns procéduraux sont moins stéréotypés.

Pas d'analyse de coût d'entraînement : la NP-PPO requiert pour chaque itération l'invocation d'un LLM pour l'attribution sémantique, l'agrégation, la génération de N_c candidats, puis le calcul du PPO Gate sur les trajectoires de batch. Aucun chiffrage de tokens dépensés pendant l'apprentissage, ce qui rend la comparaison coût/performance avec un fine-tuning RL réel impossible.

Robustesse statistique limitée : 50 épisodes par setting, écarts-types parfois larges (Skill-Pro sur Mastermind-Extreme : 0,333 ± 0,118), pas de tests de significativité. Les écarts en cross-agent sont parfois dans la barre d'erreur des baselines.

Validation de la PPO Gate : le ratio d'importance ρ_t = π_LLM(a_t|s_t,ω')/π_LLM(a_t|s_t,ω) suppose qu'on peut évaluer la log-probabilité d'actions historiques sous deux skills différents. Sur des LLMs accessibles uniquement via API sans logprobs (cas fréquent en production), cette mécanique n'est pas implémentable. Le papier ne discute pas cette contrainte.

Hypothèse forte sur l'attribution rétrospective : le gradient sémantique repose sur la capacité d'un LLM à diagnostiquer correctement la cause d'un échec dans une trajectoire. Le case study en appendice D montre un diagnostic plausible sur Mastermind, mais aucune validation systématique de la qualité d'attribution n'est fournie.

Les auteurs reconnaissent en F.1 que la représentation explicite des skills diverge de la mémoire procédurale humaine implicite, et évoquent une compression future en code ou politiques latentes. Cette honnêteté est appréciable mais ne compense pas l'absence de comparaison à des baselines de fine-tuning paramétrique léger (LoRA, RFT) qui constituent le concurrent direct.

Reproductibilité

Code disponible sur github.com/Miracle1207/Skill-Pro. Les benchmarks (ALFWorld, TextArena) sont publics. Les backbones (Qwen3-32B, Gemma-2-9B, etc.) sont accessibles. Les prompts complets sont fournis en appendice E (six templates : décision, terminaison, gradient sémantique, évolution, summarization pour ablation, évolution sans gradient). L'algorithme 1 est explicite. Les hyperparamètres ne sont pas tous tabulés (taille de batch B, capacité K, ε de clipping, N_c) mais devraient être dans le code. Reproductibilité fonctionnelle plausible avec un effort modéré.

Impact et applications

Le papier arrive dans un contexte où l'ingénierie de skills devient un axe central pour les agents LLM, avec Claude Agent Skills d'Anthropic comme référence industrielle. Skill-Pro propose une voie d'auto-apprentissage là où Anthropic mise sur l'encodage manuel. Si la mécanique se généralise, on disposerait d'un mécanisme d'amélioration continue pour les agents en production sans pipeline de fine-tuning.

L'applicabilité industrielle dépend de deux facteurs non résolus : (1) le coût en tokens de la boucle d'évolution, (2) la capacité d'évaluer ρ_t sur des LLMs propriétaires. Une variante "PPO Gate par évaluation comportementale" (rerun en simulation) serait nécessaire pour le déploiement réel.

L'idée de gradient sémantique étend TextGrad au sequential decision-making et pourrait essaimer au-delà des skills, vers l'évolution de prompts, de tools schemas ou de policies de retrieval.

Positionnement dans la littérature

Skill-Pro se positionne entre plusieurs lignées : les agents skill-centric (Voyager, Cradle, GITM), les frameworks de mémoire procédurale récents (LegoMem, MemP), et les méthodes d'optimisation de prompts (TextGrad, GEPA). La nouveauté revendiquée tient à l'évolution autonome du pool via une mécanique PPO transposée, là où Voyager s'appuie sur un curriculum manuel et Memento optimise la politique de retrieval plutôt que le contenu mémorisé.

Le papier est explicite sur la distinction avec Memento (factorisation similaire mais focus sur μ vs Ω) et MemRL (RL sur la mémoire épisodique). La comparaison avec GEPA, qui propose une évolution réflexive de prompts surpassant le RL, manque dans l'évaluation expérimentale alors qu'elle serait directement comparable conceptuellement.
