7 must-use security tools for those who vibe code [ALL FREE]
most vibe coders run no security tools, even though most of the vibe coded repos have big vulnerabilities.

these are the 7 tools you can run on your vibe-coded repo before it ships:

1. vibeship scanner

→
github.com/vibeforge1111/vibeship-scanner
→
scanner.vibeship.co
what it does: bundles opengrep (SAST), trivy (dep CVEs), gitleaks (secrets), and npm audit. [verify: 2,200+ rules across 15+ languages]. every finding comes with a Master AI Fix Prompt you paste into claude code.
use case: paste any public github repo URL, full scan in minutes, no signup. self-hostable.
disclosure: i built this.

2. trail of bits skills

→
github.com/trailofbits/skills
what it does: 5-plugin bundle. SAST, SCA via snyk MCP, code audit, patterns. the gold standard for claude code skills.
use case: load once, every code change the agent makes gets audited in-chat before you merge.

3. security-reviewer

→
jeffallan.github.io/claude-skills/skills/security/security-reviewer
what it does: multi-scanner orchestrator. runs semgrep, bandit, ESLint security, gosec, npm audit, gitleaks, trufflehog in sequence.
use case: scanner fleet behavior without installing and wiring each tool yourself.

4. vibe-security-skill

→
github.com/raroque/vibe-security-skill
what it does: audits for the exact bug classes AI coding assistants produce. missing auth checks, unvalidated input, hardcoded test keys, unsafe SQL concat.
use case: narrow purpose, high precision. the "vibe coder's fire alarm."

5. llm guard

→
github.com/protectai/llm-guard
· [2.9k stars]
what it does: [verify: 15 input + 20 output scanners]. blocks prompt injection, PII leaks, toxic outputs, jailbreaks.
use case: wrap your LLM call in it. every prompt and response gets filtered before it reaches your app logic.

6. shannon

→
github.com/KeygraphHQ/shannon
· [40k+ stars]
what it does: autonomous white-box AI pentester. reads your source, derives business-logic invariants (security properties unique to YOUR app), executes real exploits. [verify: 96.15% on XBOW benchmark].
use case: point at staging, let it land real payloads. never prod. shannon is "the red team to your vibe-coding blue team."

7. checkov

→
github.com/bridgecrewio/checkov
· [8.7k+ stars]
what it does: terraform, cloudformation, kubernetes, serverless, helm. the public S3 bucket your model forgot to lock down.
use case: any vibe-coded project with cloud infra. paired with vibeship scanner covers your two biggest attack surfaces.
