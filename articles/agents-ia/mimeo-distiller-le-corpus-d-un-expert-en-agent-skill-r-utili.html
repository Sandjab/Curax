Cloning the Mind of an Expert: a Tool for Scientists (mimeo)
Whenever join a new field, the highest-leverage thing I do is read everything one or two researchers had ever written. Not just the conclusions. The way they framed problems, the heuristics they used, the things they argued were still unsolved.
That kind of tacit knowledge transfer is the real moat in science. And it is exactly the thing AI agents struggle to replicate, because the default instinct is to grep papers for facts instead of internalizing how someone thinks.
A few weeks ago we quietly pushed mimeo to GitHub, a small open-source tool that tries to close that gap. It has been getting some use, and I wanted to write up what it is and why we think scientists in particular might find it interesting.

What it does

Give mimeo an expert's name. It will:
  1. Disambiguate who you mean, so "John Smith" doesn't silently blend an economist, a basketball coach, and a novelist into one Frankenstein skill.
  2. Discover their public corpus via
    @p0
    Search across six intent buckets: essays, talks, interviews, podcasts, frameworks, books.
  3. Fetch the full content. Web pages via
    @p0
    extract, YouTube via captions, podcasts via optional Whisper transcription.
  4. Distill each source using an LLM into a structured extraction of principles, frameworks, mental models, quotes, and anti-patterns.
  5. Cluster and rank across sources, so ideas that recur become first-class signal while one-off quips fade.
  6. Emit either a SKILL.md (on-demand, triggered by description matching) or an AGENTS.md (always-on, loaded at the start of every agent session). You can ask for both.
One command:
bash
uv run mimeo "Jane Goodall"

Why scientists should care

A few use cases we have been thinking about.
Encoding a research philosophy. Every lab has tacit norms about what counts as a good question, how to interpret a borderline result, when to chase a confound. Most of this lives in PI conversations and never makes it into the methods section. mimeo gives you a way to crystallize a public corpus into a portable artifact your agents can reason with.
Building agents that reason like a domain pioneer. Want a hypothesis-generation agent shaped by Sydney Brenner's writings? A clinical reasoning agent influenced by Atul Gawande's work on checklists? mimeo will not give you the person, but it will give you a structured digest of how they argue and what they prioritize, in a format your agent can actually load.
Reproducibility of analytical style. We talk a lot about reproducibility of results. We rarely talk about reproducibility of reasoning. Agent Skills are one way to write down how a particular thinker approaches uncertainty and run the same playbook across new problems.
Augmenting AI co-scientists. This is the one closest to home for us. At
K-Dense
we are building multi-agent systems that do autonomous scientific research, and loading a distilled expert skill into an agent's planning loop changes the conversation. The agent is no longer just retrieving from PubMed. It is reasoning under a specific set of priors.

A note on methodology

The pipeline itself was designed to behave like a small scientific instrument.
Multi-bucket discovery beats a single keyword search, because experts produce differently shaped content in different venues. Disambiguation runs upstream of everything else, because nothing destroys a skill faster than silently merging two careers. Distillation is per-source so each piece can be inspected and audited. Clustering is cross-source, so cross-document recurrence drives the signal.
Every intermediate artifact is cached in _workspace/. You can open them, audit them, swap out the model, re-run any stage. This is meant to be a tool, not a black box.

What it is not

mimeo is not a substitute for reading. It is a forcing function for turning a corpus into something an agent can use. If you care about a thinker, you should still read them.
It is also not a perfect biographer. The output reflects what is publicly available and indexable. For figures with rich written corpuses (essayists, founders who blog, public intellectuals, scientists who give a lot of talks) it works well. For figures whose ideas live mostly in private papers, lab notebooks, or unindexed talks, the output will be thinner. We have some ideas about extending it to PDFs of published work, and we would love to hear what you would want.
