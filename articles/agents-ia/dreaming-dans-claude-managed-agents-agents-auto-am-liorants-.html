What Dreaming Actually Is

Dreaming is a scheduled process inside Claude Managed Agents.
While the agent is idle, Dreaming reads the session logs and the memory store.
It spots patterns. Recurring mistakes. Routines the agent converges on. Preferences pulled from your corrections.
Then it produces a new memory store. Duplicates merged. Stale entries replaced. New insights added.
The agent that wakes up tomorrow is sharper than the one you closed tonight.

The 8-Minute Setup

Open Claude Console. Go to your Managed Agent.
Find the section labeled Dreaming cadence.
Pick a schedule. Hourly, daily, weekly, or manual trigger.
For most setups daily is the right default. Set it to fire at 3 AM your time. The agent dreams while you sleep.
Pick the control level. Auto-update lets Dreaming rewrite memory itself. Review mode lets you approve the diff each morning.
Start in review mode for the first 7 days so you see what it changes. Flip to auto-update once you trust it.
Hit save. Done.

Why It Compounds

A regular agent works at the same level on day 100 as on day 1, unless you tune it by hand.
A dreaming agent gets sharper every night. Every dream incorporates yesterday's corrections. Mistakes you flagged on Monday show up as memory updates Tuesday.
The math gets unreasonable fast. 30 corrections in week 1 become 30 memory entries by week 2. The agent in your console at the end of the month is running on every correction you ever made.
After 30 days the agent knows your preferences, your edge cases, your style. After 90 days it knows things you forgot you taught it.
That is the whole point.

The Sales Pipeline That Trains Itself

Set up an agent that reads new leads, scores them, drafts the first reply in your voice, and flags hot ones for you.
The first week you correct it constantly. The lead it scored as hot was a competitor. The reply was too long. The signature was off.
Dreaming logs all of it. Day 8 the agent already knows your hot-lead pattern. Day 15 replies need less editing. Day 30 you barely look at them.
You did not retrain the agent. You used it normally and let it dream.

The Content Gate That Learns Your Style

Set up an agent that reads every draft before it lands. It runs voice checks, hook checks, structure rules.
The first 10 drafts you push back hard. Wrong tone. Wrong specificity. Wrong length.
Dreaming picks up the corrections. Day 12 the gate catches the same issues without you flagging them.
Day 30 it catches a tone violation you never explicitly named because it noticed you reject every draft with that specific shape.
This is the workflow that pays for the entire setup.

The Monday Brief That Compounds

Set up an agent that pulls competitor moves in your client's industry every Monday morning.
Day one it brings you 12 items. 8 are noise.
You flag the 4 that mattered. You tell it which sources to trust.
Dreaming logs every signal you flagged and every source you favored.
By week 4 the Monday brief lands with 5 items, all relevant. By week 8 it is the only source you read for that client.
You did not write a research SOP. The agent wrote it for you while you slept.
