Building a Neural Network from Scratch in Pure x86-64 Assembly
Yeah, you read that right. We're doing this at the lowest level possible. In this article we're going to building a tiny XOR neural network in x86-64 assembly. No libraries. No shortcuts. Just you and the CPU.
Prerequisites: You should know the basics of what a neural network is (layers, weights, biases, activation functions). Some assembly experience helps, but I'll explain things as we go. You'll need NASM and GCC installed on a Linux box.

1. The Game Plan

We're going to solve the XOR problem. It's the "hello world" of neural networks because a single-layer perceptron can't solve it. You need at least one hidden layer.
Here's the XOR truth table:
Our network architecture:
markdown
Input Layer (2 neurons)
        ↓
Hidden Layer (2 neurons, sigmoid activation)
        ↓
Output Layer (1 neuron, sigmoid activation)
That's it. 2 --> 2 --> 1. Tiny, but enough to learn XOR.

2. Quick Refresher: What Are We Actually Computing?

Before we touch assembly, let's be crystal clear about the math. If this is boring to you, skip ahead. If not, read carefully because this is what we're going to translate into instructions.
Forward pass (hidden layer):
h1=sigmoid(w1∗x1+w2∗x2+b1)h1 = sigmoid(w1*x1 + w2*x2 + b1)
h2=sigmoid(w3∗x1+w4∗x2+b2)h2 = sigmoid(w3*x1 + w4*x2 + b2)
Forward pass (output layer):
output=sigmoid(w5∗h1+w6∗h2+b3)output = sigmoid(w5*h1 + w6*h2 + b3)
Loss (mean squared error for one sample):
error=target−outputerror = target - output
loss=0.5∗error2loss = 0.5 * error^2
Backpropagation: We compute how much each weight contributed to the error, then nudge it in the right direction. The chain rule is doing all the heavy lifting here.
For the output layer:
markdown
d_output = error * sigmoid_derivative(output)
For the hidden layer:
markdown
d_h1 = d_output * w5 * sigmoid_derivative(h1)
d_h2 = d_output * w6 * sigmoid_derivative(h2)
Weight update:
markdown
weight = weight + learning_rate * delta * input_to_that_weight
That's the entire algorithm. Now let's make the CPU do it.

3. Setting Up: Data Section and Memory Layout

In assembly, there's no float weights[6]. You manually reserve bytes in the .data or .bss section and keep track of what's where. This is the part where you realize how spoiled high-level languages have made us.
Here's our data section:
x86asm
section .data
    ; Training data (XOR)
    ; Each sample: input1, input2, target
    ; Stored as 32-bit floats (4 bytes each)
    train_data:
        dd 0.0, 0.0, 0.0      ; 0 XOR 0 = 0
        dd 0.0, 1.0, 1.0      ; 0 XOR 1 = 1
        dd 1.0, 0.0, 1.0      ; 1 XOR 0 = 1
        dd 1.0, 1.0, 0.0      ; 1 XOR 1 = 0

    num_samples:  dd 4
    num_epochs:   dd 10000
    learning_rate: dd 0.5

    ; === Weights (initialized with hand-picked values) ===
    ; In real life you'd randomize these, but let's keep it simple.
    ; Hidden layer weights: w1, w2, w3, w4
    w1: dd 0.5
    w2: dd 0.3
    w3: dd 0.7
    w4: dd 0.2

    ; Hidden layer biases
    b1: dd 0.1
    b2: dd 0.1

    ; Output layer weights: w5, w6
    w5: dd 0.4
    w6: dd 0.6

    ; Output layer bias
    b3: dd 0.1

    ; Constants we'll need
    one:       dd 1.0
    neg_one:   dd -1.0
    half:      dd 0.5

section .bss
    ; Intermediate values (forward pass)
    z1:     resd 1    ; pre-activation hidden neuron 1
    z2:     resd 1    ; pre-activation hidden neuron 2
    h1:     resd 1    ; post-activation hidden neuron 1
    h2:     resd 1    ; post-activation hidden neuron 2
    z_out:  resd 1    ; pre-activation output
    output: resd 1    ; final output

    ; Gradients (backprop)
    d_out:  resd 1    ; output delta
    d_h1:   resd 1    ; hidden 1 delta
    d_h2:   resd 1    ; hidden 2 delta
Let me explain what's going on here:
  • dd means "define double-word", which is 4 bytes, the size of a 32-bit float. Each dd 0.5 reserves 4 bytes and stores the float value 0.5 there.
  • resd 1 means "reserve space for 1 double-word", the same 4 bytes but uninitialized. We will write to these during computation.
  • Every weight, bias, input, and intermediate value gets its own labeled memory location. In Python you'd just use variables. Here, you're the memory manager.
The training data is laid out flat: 4 samples × 3 floats each = 12 floats = 48 bytes, all sitting in a row. We'll step through them with pointer arithmetic during training.

4. Step 1: The Forward Pass

This is where the actual "thinking" happens. We take inputs, multiply by weights, add biases, and pass through sigmoid. Let's do the hidden layer first.
; forward_pass
; Expects: xmm0 = x1 (input 1), xmm1 = x2 (input 2)
; Computes: h1, h2, output (stores to memory)

forward_pass:
    push rbp
    mov rbp, rsp

    ; Hidden neuron 1: z1 = w1*x1 + w2*x2 + b1
    movss xmm2, [w1]        ; xmm2 = w1
    mulss xmm2, xmm0        ; xmm2 = w1 * x1
    movss xmm3, [w2]        ; xmm3 = w2
    mulss xmm3, xmm1        ; xmm3 = w2 * x2
    addss xmm2, xmm3        ; xmm2 = w1*x1 + w2*x2
    addss xmm2, [b1]        ; xmm2 = w1*x1 + w2*x2 + b1
    movss [z1], xmm2        ; store z1

    ; Apply sigmoid to z1 -> h1
    ; (xmm2 already has z1)
    call sigmoid             ; result in xmm0
    movss [h1], xmm0        ; store h1

    ; Reload inputs (sigmoid trashed our registers)
    ; We need to reload x1, x2 from the training data pointer
    ; (we'll handle this in the training loop. For now, assume
    ;  we save/restore them)

    ; Hidden neuron 2: z2 = w3*x1 + w4*x2 + b2
    movss xmm2, [w3]
    mulss xmm2, xmm0        ; wait... xmm0 is h1 now, not x1!
    ; ^^^ This is a classic assembly trap. You have to be super
    ; careful about which register holds what.
Stop. Let's talk about the register problem.
This is the #1 thing that bites you in assembly neural nets. In Python, you write h1 = sigmoid(w1*x1 + w2*x2 + b1) and then x1 is still x1. In assembly, calling a function like sigmoid can destroy your register values. The System V AMD64 calling convention says xmm0-xmm7 are caller-saved, meaning any function call can overwrite them.
So we need to save our inputs to memory before calling sigmoid, then reload them. Here's the corrected version:
x86asm
section .bss
    ; Add these to save inputs across function calls
    save_x1: resd 1
    save_x2: resd 1

section .text

; forward_pass
; Expects: x1 at [save_x1], x2 at [save_x2]
; Computes: h1, h2, output

forward_pass:
    push rbp
    mov rbp, rsp

    ; Hidden neuron 1: z1 = w1*x1 + w2*x2 + b1
    movss xmm0, [save_x1]   ; xmm0 = x1
    movss xmm1, [save_x2]   ; xmm1 = x2

    movss xmm2, [w1]
    mulss xmm2, xmm0        ; w1 * x1
    movss xmm3, [w2]
    mulss xmm3, xmm1        ; w2 * x2
    addss xmm2, xmm3        ; w1*x1 + w2*x2
    addss xmm2, [b1]        ; + b1
    movss [z1], xmm2

    movss xmm0, xmm2        ; sigmoid expects input in xmm0
    call sigmoid
    movss [h1], xmm0        ; h1 = sigmoid(z1)

    ; Hidden neuron 2: z2 = w3*x1 + w4*x2 + b2
    movss xmm0, [save_x1]   ; reload x1 (sigmoid trashed it)
    movss xmm1, [save_x2]   ; reload x2

    movss xmm2, [w3]
    mulss xmm2, xmm0        ; w3 * x1
    movss xmm3, [w4]
    mulss xmm3, xmm1        ; w4 * x2
    addss xmm2, xmm3        ; w3*x1 + w4*x2
    addss xmm2, [b2]        ; + b2
    movss [z2], xmm2

    movss xmm0, xmm2
    call sigmoid
    movss [h2], xmm0        ; h2 = sigmoid(z2)

    ; Output neuron: z_out = w5*h1 + w6*h2 + b3
    movss xmm2, [w5]
    mulss xmm2, [h1]        ; w5 * h1
    movss xmm3, [w6]
    mulss xmm3, [h2]        ; w6 * h2
    addss xmm2, xmm3        ; w5*h1 + w6*h2
    addss xmm2, [b3]        ; + b3
    movss [z_out], xmm2

    movss xmm0, xmm2
    call sigmoid
    movss [output], xmm0    ; output = sigmoid(z_out)

    pop rbp
    ret
Let's break down the key instructions you're seeing:
  • xmm0, [w1]: Load a 32-bit float from memory address w1 into register xmm0
  • mulss xmm2, xmm0: Multiply the float in xmm2 by the float in xmm0, store result in xmm2
  • addss xmm2, xmm3: Add xmm3 to xmm2
  • movss [z1], xmm2: Store the float in xmm2 to memory address z1
The ss suffix means "scalar single-precision", so we are operating on one 32-bit float at a time. If we wanted to go faster, we would use ps (packed single) to process 4 floats at once with SIMD. But let’s learn to walk before we run.

5. Step 2: The Activation Function (Sigmoid)

The sigmoid function is σ(x) = 1 / (1 + e^(-x)). This is where things get interesting because assembly doesn't have an exp() instruction.
Well, technically x87 FPU has f2xm1 which computes 2^x - 1, and we can use the identity e^x = 2^(x * log2(e)) to build exp() from that. It's gross but it works.
x86asm
; sigmoid
; Input:  xmm0 = x (32-bit float)
; Output: xmm0 = sigmoid(x)
; Trashes: xmm1, xmm2, and x87 FPU stack

sigmoid:
    push rbp
    mov rbp, rsp
    sub rsp, 16              ; scratch space on stack

    ; Step 1: Compute -x
    movss xmm1, [neg_one]
    mulss xmm0, xmm1        ; xmm0 = -x

    ; Step 2: Compute exp(-x) using x87 FPU
    ; Strategy: e^(-x) = 2^(-x * log2(e))
    movss [rsp], xmm0       ; put -x on stack
    fld dword [rsp]          ; load -x onto x87 FPU stack (ST0 = -x)
    fldl2e                   ; ST0 = log2(e), ST1 = -x
    fmulp                    ; ST0 = -x * log2(e)

    ; Now compute 2^(ST0)
    ; f2xm1 only works for values in [-1, 1], so we split into
    ; integer part and fractional part
    fld st0                  ; duplicate: ST0 = ST1 = -x*log2(e)
    frndint                  ; ST0 = round(-x*log2(e)) = integer part
    fsub st1, st0            ; ST1 = fractional part
    fxch                     ; ST0 = fractional, ST1 = integer
    f2xm1                   ; ST0 = 2^(fractional) - 1
    fld1                     ; ST0 = 1.0
    faddp                    ; ST0 = 2^(fractional)
    fscale                   ; ST0 = 2^(fractional) * 2^(integer) = 2^(total) = exp(-x)
    fstp st1                 ; clean up FPU stack

    fstp dword [rsp]         ; store exp(-x) to stack
    movss xmm0, [rsp]       ; xmm0 = exp(-x)

    ; Step 3: Compute 1 / (1 + exp(-x))
    addss xmm0, [one]       ; xmm0 = 1 + exp(-x)
    movss xmm1, [one]
    divss xmm1, xmm0        ; xmm1 = 1 / (1 + exp(-x))
    movss xmm0, xmm1        ; xmm0 = sigmoid(x)

    add rsp, 16
    pop rbp
    ret
Yeah. That's a lot of code for 1/(1+exp(-x)). Welcome to assembly.
Let me walk through what the x87 FPU stuff is doing, because it probably looks like alien language:
The x87 FPU is a stack-based floating-point unit that's been around since the 8087 coprocessor in 1980. It uses a stack of 8 registers called ST0 through ST7. You push values on, do operations, and pop results off.
  • fld dword [rsp]: push a 32-bit float from memory onto the FPU stack
  • fldl2e: push the constant log₂(e) onto the stack (the CPU literally has this built in)
  • fmulp: multiply ST0 × ST1, pop both, push the result
  • frndint: round ST0 to the nearest integer
  • f2xm1: compute 2^(ST0) - 1 (only works for ST0 in [-1, 1])
  • fscale: compute ST0 × 2^(ST1) (this is how we recombine the integer and fractional parts)
The trick with f2xm1 is that it only works for inputs between -1 and 1. So we split our exponent into integer + fraction parts, compute 2^fraction with f2xm1, then scale by 2^integer with fscale. This is a standard technique.

6. Step 3: Computing the Loss

The loss tells us how wrong we are. We use mean squared error: loss = 0.5 * (target - output)^2. We also need the raw error for backprop.
x86asm
; compute_error
; Expects: xmm0 = target
; Uses: [output] from forward pass
; Stores: error in xmm0 (target - output)

compute_error:
    ; error = target - output
    subss xmm0, [output]    ; xmm0 = target - output
    ; That's it. That's the function.
    ret
Yep. One instruction plus the ret. After all that sigmoid pain, this feels nice.
We do not actually need to compute the full loss value for training; we only need the error for backprop. But if you want to track the loss for printing:
x86asm
; loss = 0.5 * error^2
movss xmm1, xmm0        ; xmm1 = error
mulss xmm1, xmm1        ; xmm1 = error^2
mulss xmm1, [half]      ; xmm1 = 0.5 * error^2
; xmm1 now holds the loss

7. Step 4: Backpropagation

This is the hardest part conceptually, but in assembly it is really just more multiplies and subtracts. We need to compute the gradients, which tell us how much each weight needs to change.
Remember, the sigmoid derivative has a nice property: σ'(x) = σ(x) * (1 - σ(x)). Since we already have σ(x) stored from the forward pass, we do not need to recompute anything.
; backprop
; Expects: error already in xmm0 (target - output)
; Uses: h1, h2, output, w5, w6 from forward pass
; Computes: d_out, d_h1, d_h2

backprop:
    push rbp
    mov rbp, rsp

    ; Output layer delta
    ; d_out = error * sigmoid'(output)
    ; sigmoid'(output) = output * (1 - output)
    movss xmm1, [output]
    movss xmm2, [one]
    subss xmm2, xmm1        ; xmm2 = 1 - output
    mulss xmm1, xmm2        ; xmm1 = output * (1 - output) = sigmoid'
    mulss xmm0, xmm1        ; xmm0 = error * sigmoid' = d_out
    movss [d_out], xmm0     ; save d_out

    ; Hidden layer deltas
    ; d_h1 = d_out * w5 * sigmoid'(h1)
    movss xmm1, [d_out]
    mulss xmm1, [w5]        ; xmm1 = d_out * w5

    movss xmm2, [h1]
    movss xmm3, [one]
    subss xmm3, xmm2        ; xmm3 = 1 - h1
    mulss xmm2, xmm3        ; xmm2 = h1 * (1 - h1) = sigmoid'(h1)
    mulss xmm1, xmm2        ; xmm1 = d_out * w5 * sigmoid'(h1) = d_h1
    movss [d_h1], xmm1

    ; d_h2 = d_out * w6 * sigmoid'(h2)
    movss xmm1, [d_out]
    mulss xmm1, [w6]        ; xmm1 = d_out * w6

    movss xmm2, [h2]
    movss xmm3, [one]
    subss xmm3, xmm2        ; xmm3 = 1 - h2
    mulss xmm2, xmm3        ; xmm2 = h2 * (1 - h2) = sigmoid'(h2)
    mulss xmm1, xmm2        ; xmm1 = d_out * w6 * sigmoid'(h2) = d_h2
    movss [d_h2], xmm1

    pop rbp
    ret
Notice the pattern? Each delta computation is the same structure:
markdown
delta = upstream_gradient * weight * sigmoid_derivative(activation)
This is the chain rule in action. The gradient "flows backward" through each connection, getting multiplied by the local derivative at each step. In Python this is one line with autograd. Here, you see every multiply.

8. Step 5: Weight Updates

Now we nudge every weight in the direction that reduces the error. The update rule is:
markdown
weight += learning_rate * delta * input_to_that_connection
x86asm
; update_weights
; Uses: d_out, d_h1, d_h2, save_x1, save_x2, h1, h2
; Modifies: w1-w6, b1-b3

update_weights:
    push rbp
    mov rbp, rsp

    ; Output layer weights
    ; w5 += lr * d_out * h1
    movss xmm0, [learning_rate]
    mulss xmm0, [d_out]     ; lr * d_out
    movss xmm1, xmm0        ; save lr * d_out for w6 and b3

    mulss xmm0, [h1]        ; lr * d_out * h1
    addss xmm0, [w5]        ; w5 + update
    movss [w5], xmm0        ; store new w5

    ; w6 += lr * d_out * h2
    movss xmm0, xmm1        ; lr * d_out
    movss xmm2, xmm1        ; save another copy for b3
    mulss xmm0, [h2]
    addss xmm0, [w6]
    movss [w6], xmm0

    ; b3 += lr * d_out
    addss xmm2, [b3]
    movss [b3], xmm2

    ; Hidden layer weights
    ; w1 += lr * d_h1 * x1
    movss xmm0, [learning_rate]
    mulss xmm0, [d_h1]      ; lr * d_h1
    movss xmm1, xmm0        ; save for w2 and b1

    mulss xmm0, [save_x1]   ; lr * d_h1 * x1
    addss xmm0, [w1]
    movss [w1], xmm0

    ; w2 += lr * d_h1 * x2
    movss xmm0, xmm1        ; lr * d_h1
    movss xmm2, xmm1        ; save for b1
    mulss xmm0, [save_x2]
    addss xmm0, [w2]
    movss [w2], xmm0

    ; b1 += lr * d_h1
    addss xmm2, [b1]
    movss [b1], xmm2

    ; w3 += lr * d_h2 * x1
    movss xmm0, [learning_rate]
    mulss xmm0, [d_h2]      ; lr * d_h2
    movss xmm1, xmm0

    mulss xmm0, [save_x1]
    addss xmm0, [w3]
    movss [w3], xmm0

    ; w4 += lr * d_h2 * x2
    movss xmm0, xmm1
    movss xmm2, xmm1        ; save for b2
    mulss xmm0, [save_x2]
    addss xmm0, [w4]
    movss [w4], xmm0

    ; b2 += lr * d_h2
    addss xmm2, [b2]
    movss [b2], xmm2

    pop rbp
    ret
This is tedious but straightforward. Every weight update is the same three instructions: load, multiply, add-to-existing-weight. Nine weights and biases = nine little update blocks.
You can see why people invented matrix libraries.

9. Step 6: The Training Loop

Now we wire everything together. For each epoch, we loop through all 4 training samples, run forward pass → compute error → backprop → update weights.
section .text
    global main
    extern printf

; Format string for printing results
section .data
    fmt_result: db "Input: %.1f, %.1f  |  Target: %.1f  |  Output: %.4f", 10, 0
    fmt_epoch:  db "Epoch %d, Loss: %.6f", 10, 0

section .text
main:
    push rbp
    mov rbp, rsp

    ; r12 = epoch counter
    ; r13 = sample counter
    ; r14 = pointer into training data
    push r12
    push r13
    push r14
    sub rsp, 8               ; align stack to 16 bytes

    xor r12, r12             ; epoch = 0

.epoch_loop:
    cmp r12d, [num_epochs]
    jge .training_done

    xor r13, r13             ; sample = 0
    lea r14, [train_data]    ; r14 points to start of training data

.sample_loop:
    cmp r13d, [num_samples]
    jge .next_epoch

    ; Load current sample
    ; Each sample is 3 floats (12 bytes): x1, x2, target
    movss xmm0, [r14]       ; x1
    movss [save_x1], xmm0
    movss xmm0, [r14 + 4]   ; x2
    movss [save_x2], xmm0
    ; target is at [r14 + 8], we'll load it when needed

    ; Forward pass
    call forward_pass

    ; Compute error
    movss xmm0, [r14 + 8]   ; load target
    call compute_error       ; xmm0 = error = target - output

    ; Backpropagation
    call backprop            ; compute deltas

    ; Update weights
    call update_weights

    ; Move to next sample
    add r14, 12              ; advance pointer by 3 floats (12 bytes)
    inc r13
    jmp .sample_loop

.next_epoch:
    inc r12
    jmp .epoch_loop

.training_done:
    ; Print final results
    lea r14, [train_data]
    xor r13, r13

.print_loop:
    cmp r13d, [num_samples]
    jge .done

    ; Load sample and run forward pass
    movss xmm0, [r14]
    movss [save_x1], xmm0
    movss xmm0, [r14 + 4]
    movss [save_x2], xmm0
    call forward_pass

    ; Print: printf(fmt, x1, x2, target, output)
    ; System V calling convention: float args go in xmm0-xmm7
    ; rdi = format string, rax = number of vector (xmm) args
    lea rdi, [fmt_result]
    movss xmm0, [save_x1]
    cvtss2sd xmm0, xmm0     ; printf needs doubles, not floats
    movss xmm1, [save_x2]
    cvtss2sd xmm1, xmm1
    movss xmm2, [r14 + 8]
    cvtss2sd xmm2, xmm2
    movss xmm3, [output]
    cvtss2sd xmm3, xmm3
    mov rax, 4               ; 4 float/double args in xmm registers
    call printf

    add r14, 12
    inc r13
    jmp .print_loop

.done:
    add rsp, 8               ; undo alignment padding
    pop r14
    pop r13
    pop r12

    xor eax, eax             ; return 0
    leave
    ret
A few things to notice:
Pointer arithmetic: We use r14 as a pointer into the training data and advance it by 12 bytes (3 floats × 4 bytes) after each sample. This is how you "iterate over an array" in assembly.
cvtss2sd: printf expects double (64-bit) arguments for %f, but we've been working with float (32-bit) everywhere. So we have to convert before printing. Classic C ABI headache.
mov rax, 4: The System V AMD64 calling convention requires you to put the number of XMM register arguments in rax before calling variadic functions like printf. Forget this and you'll get garbage output or a segfault.

10. Full Code

Here's the complete program in one block. Save this as nn.asm:
x86asm
; nn.asm: XOR Neural Network in x86-64 Assembly
; Assemble: nasm -f elf64 nn.asm -o nn.o
; Link:     gcc nn.o -o nn -lm -no-pie
; Run:      ./nn

section .data
    ; Training data: x1, x2, target
    train_data:
        dd 0.0, 0.0, 0.0
        dd 0.0, 1.0, 1.0
        dd 1.0, 0.0, 1.0
        dd 1.0, 1.0, 0.0

    num_samples:   dd 4
    num_epochs:    dd 10000
    learning_rate: dd 0.5

    ; Hidden layer weights and biases
    w1: dd 0.5
    w2: dd 0.3
    w3: dd 0.7
    w4: dd 0.2
    b1: dd 0.1
    b2: dd 0.1

    ; Output layer weights and bias
    w5: dd 0.4
    w6: dd 0.6
    b3: dd 0.1

    ; Constants
    one:       dd 1.0
    neg_one:   dd -1.0
    half:      dd 0.5

    ; Print format strings
    fmt_result: db "Input: %.1f, %.1f  |  Target: %.1f  |  Output: %.4f", 10, 0
    fmt_header: db "Training complete (10000 epochs)", 10, 0

section .bss
    z1:      resd 1
    z2:      resd 1
    h1:      resd 1
    h2:      resd 1
    z_out:   resd 1
    output:  resd 1
    d_out:   resd 1
    d_h1:    resd 1
    d_h2:    resd 1
    save_x1: resd 1
    save_x2: resd 1

section .text
    global main
    extern printf

; SIGMOID
sigmoid:
    push rbp
    mov rbp, rsp
    sub rsp, 16

    movss xmm1, [neg_one]
    mulss xmm0, xmm1
    movss [rsp], xmm0
    fld dword [rsp]
    fldl2e
    fmulp
    fld st0
    frndint
    fsub st1, st0
    fxch
    f2xm1
    fld1
    faddp
    fscale
    fstp st1
    fstp dword [rsp]
    movss xmm0, [rsp]

    addss xmm0, [one]
    movss xmm1, [one]
    divss xmm1, xmm0
    movss xmm0, xmm1

    add rsp, 16
    pop rbp
    ret

; FORWARD PASS
forward_pass:
    push rbp
    mov rbp, rsp

    ; Hidden neuron 1
    movss xmm0, [save_x1]
    movss xmm1, [save_x2]
    movss xmm2, [w1]
    mulss xmm2, xmm0
    movss xmm3, [w2]
    mulss xmm3, xmm1
    addss xmm2, xmm3
    addss xmm2, [b1]
    movss [z1], xmm2
    movss xmm0, xmm2
    call sigmoid
    movss [h1], xmm0

    ; Hidden neuron 2
    movss xmm0, [save_x1]
    movss xmm1, [save_x2]
    movss xmm2, [w3]
    mulss xmm2, xmm0
    movss xmm3, [w4]
    mulss xmm3, xmm1
    addss xmm2, xmm3
    addss xmm2, [b2]
    movss [z2], xmm2
    movss xmm0, xmm2
    call sigmoid
    movss [h2], xmm0

    ; Output neuron
    movss xmm2, [w5]
    mulss xmm2, [h1]
    movss xmm3, [w6]
    mulss xmm3, [h2]
    addss xmm2, xmm3
    addss xmm2, [b3]
    movss [z_out], xmm2
    movss xmm0, xmm2
    call sigmoid
    movss [output], xmm0

    pop rbp
    ret

; BACKPROP
backprop:
    push rbp
    mov rbp, rsp

    ; d_out = error * sigmoid'(output)
    movss xmm1, [output]
    movss xmm2, [one]
    subss xmm2, xmm1
    mulss xmm1, xmm2
    mulss xmm0, xmm1
    movss [d_out], xmm0

    ; d_h1 = d_out * w5 * sigmoid'(h1)
    movss xmm1, [d_out]
    mulss xmm1, [w5]
    movss xmm2, [h1]
    movss xmm3, [one]
    subss xmm3, xmm2
    mulss xmm2, xmm3
    mulss xmm1, xmm2
    movss [d_h1], xmm1

    ; d_h2 = d_out * w6 * sigmoid'(h2)
    movss xmm1, [d_out]
    mulss xmm1, [w6]
    movss xmm2, [h2]
    movss xmm3, [one]
    subss xmm3, xmm2
    mulss xmm2, xmm3
    mulss xmm1, xmm2
    movss [d_h2], xmm1

    pop rbp
    ret

; UPDATE WEIGHTS
update_weights:
    push rbp
    mov rbp, rsp

    ; Output layer
    movss xmm0, [learning_rate]
    mulss xmm0, [d_out]
    movss xmm1, xmm0

    movss xmm4, xmm0
    mulss xmm4, [h1]
    addss xmm4, [w5]
    movss [w5], xmm4

    movss xmm4, xmm1
    mulss xmm4, [h2]
    addss xmm4, [w6]
    movss [w6], xmm4

    movss xmm4, xmm1
    addss xmm4, [b3]
    movss [b3], xmm4

    ; Hidden layer (neuron 1)
    movss xmm0, [learning_rate]
    mulss xmm0, [d_h1]
    movss xmm1, xmm0

    movss xmm4, xmm0
    mulss xmm4, [save_x1]
    addss xmm4, [w1]
    movss [w1], xmm4

    movss xmm4, xmm1
    mulss xmm4, [save_x2]
    addss xmm4, [w2]
    movss [w2], xmm4

    movss xmm4, xmm1
    addss xmm4, [b1]
    movss [b1], xmm4

    ; Hidden layer (neuron 2)
    movss xmm0, [learning_rate]
    mulss xmm0, [d_h2]
    movss xmm1, xmm0

    movss xmm4, xmm0
    mulss xmm4, [save_x1]
    addss xmm4, [w3]
    movss [w3], xmm4

    movss xmm4, xmm1
    mulss xmm4, [save_x2]
    addss xmm4, [w4]
    movss [w4], xmm4

    movss xmm4, xmm1
    addss xmm4, [b2]
    movss [b2], xmm4

    pop rbp
    ret

; MAIN
main:
    push rbp
    mov rbp, rsp
    push r12
    push r13
    push r14
    sub rsp, 8               ; align stack to 16 bytes

    xor r12, r12

.epoch_loop:
    cmp r12d, [num_epochs]
    jge .training_done
    xor r13, r13
    lea r14, [train_data]

.sample_loop:
    cmp r13d, [num_samples]
    jge .next_epoch

    movss xmm0, [r14]
    movss [save_x1], xmm0
    movss xmm0, [r14 + 4]
    movss [save_x2], xmm0

    call forward_pass

    movss xmm0, [r14 + 8]
    subss xmm0, [output]

    call backprop
    call update_weights

    add r14, 12
    inc r13
    jmp .sample_loop

.next_epoch:
    inc r12
    jmp .epoch_loop

.training_done:
    ; Print header
    lea rdi, [fmt_header]
    xor eax, eax
    call printf

    ; Print results
    lea r14, [train_data]
    xor r13, r13

.print_loop:
    cmp r13d, [num_samples]
    jge .done

    movss xmm0, [r14]
    movss [save_x1], xmm0
    movss xmm0, [r14 + 4]
    movss [save_x2], xmm0
    call forward_pass

    lea rdi, [fmt_result]
    movss xmm0, [save_x1]
    cvtss2sd xmm0, xmm0
    movss xmm1, [save_x2]
    cvtss2sd xmm1, xmm1
    movss xmm2, [r14 + 8]
    cvtss2sd xmm2, xmm2
    movss xmm3, [output]
    cvtss2sd xmm3, xmm3
    mov rax, 4
    call printf

    add r14, 12
    inc r13
    jmp .print_loop

.done:
    add rsp, 8               ; undo alignment padding
    pop r14
    pop r13
    pop r12
    xor eax, eax
    leave
    ret

; Mark stack as non-executable (suppresses linker warning)
section .note.GNU-stack noalloc noexec nowrite progbits

# Assemble
nasm -f elf64 nn.asm -o nn.o

# Link with GCC (we need libc for printf)
gcc nn.o -o nn -lm -no-pie

# Run
./nn

Input: 0.0, 1.0  |  Target: 1.0  |  Output: 0.9541

The outputs will not be exactly 0 and 1 because the sigmoid never quite reaches those values, but they should be close. If your outputs are all around 0.5, the network did not converge. Try different initial weights or increase the number of epochs.

Where to Go From Here

  • Add ReLU instead of sigmoid. It's way simpler in assembly and trains faster.
  • Use SIMD (packed operations) to process multiple neurons at once. Replace mulss with mulps and watch your hidden layer compute in one instruction instead of two.
  • Write the weight initialization using a random number generator instead of hard-coded values.
Keep building. Keep learning.
