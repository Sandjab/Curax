08 - Transformer Layers and Self-Attention
Most people hear “attention” and imagine an LLM choosing what to focus on like a human. That is close enough to be useful, but not precise enough to understand what is actually happening. In a transformer, attention is the mechanism that lets every token update itself by looking at other tokens in the sequence. That one idea explains a lot:
  • Why word order matters
  • Why context changes meaning
  • Why long prompts cost more compute
  • Why transformer layers can build surprisingly rich internal representations
  • Why the same token can mean different things in different sentences
This article gives you the mental model without drowning you in matrix math.

What you’ll learn

By the end, you’ll understand:
  • What a token representation is
  • What self-attention actually does
  • Why attention weights matter
  • Why transformers stack many layers
  • What multi-head attention adds
  • How this connects back to local LLM inference

A token is not just a token ID anymore

In earlier articles, we talked about tokens as chunks of text converted into token IDs. Example:
“The cat sat”
might become something like:
  • The
  • cat
  • sat
Each token starts as an ID, basically a number from the model’s vocabulary. But the transformer does not work directly with plain token IDs. It turns each token ID into a vector. A vector is a list of numbers that represents the token inside the model. You can think of this as the model’s internal working form for that token. At the start, the representation mostly says:
“This is the token cat.”
But after passing through transformer layers, the representation becomes more contextual:
“This is cat, and in this sentence it is probably the animal, it is the subject, and it relates strongly to sat.”
That shift is the whole point. The model is not just storing tokens. It is repeatedly updating what each token means in context. Takeaway: A transformer turns token IDs into internal representations, then refines those representations layer by layer.

Self-attention lets tokens look at each other

Self-attention means tokens in a sequence compare themselves with other tokens in the same sequence. That is why it is called “self” attention. The sequence attends to itself. Suppose the prompt is:
The animal didn’t cross the street because it was tired.
A human immediately asks:
What does “it” refer to?
Probably “the animal.” The model needs a way to connect those related tokens. Self-attention gives it that mechanism. When processing the token it, the model can assign different levels of importance to earlier tokens:
  • The: low importance
  • animal: high importance
  • didn’t: some importance
  • cross: some importance
  • street: lower importance
  • because: structural importance
  • tired: high local importance
This does not mean the model has a symbolic grammar engine or a database of meanings. It means the model has learned numerical patterns that help each token representation update based on other relevant tokens. Takeaway: Self-attention lets each token update its meaning by using information from other tokens in the same context.

Attention weights decide which relationships matter most

Attention is not all-or-nothing. A token does not simply “look at” one other token. Instead, it distributes attention across many tokens. Some tokens matter more. Some matter less. Those importance levels are often called attention weights. A simplified version looks like this:
plaintext
Token being updated: "it"

Looks at:
- animal: 0.45
- street: 0.10
- because: 0.15
- tired: 0.25
- other tokens: 0.05
These numbers are not hand-written rules. They are produced by the model during inference based on:
  • The current token
  • The surrounding tokens
  • The learned weights of the model
  • The layer being used
  • The attention head doing the comparison
This is why context matters so much.
The same token can get a different representation in different sentences. Compare:
The animal crossed the street because it was wide.
Here, “it” probably refers to the street. Now compare:
The animal crossed the street because it was scared.
Here, “it” probably refers to the animal. Same token. Similar sentence. Different relationship. Self-attention is one of the mechanisms that lets the model adjust. Takeaway: Attention weights are the model’s learned way of deciding which token relationships should influence the current token most.

Attention is how context changes meaning

Words are ambiguous. Tokens are even more ambiguous. The token bank could mean:
  • A financial institution
  • The side of a river
  • A verb meaning to rely on something
  • Part of a phrase or name
The model cannot know the right meaning from the token alone. It needs context. Example:
She deposited money at the bank.
The nearby tokens deposited and money make the financial meaning more likely. Example:
They sat on the bank of the river.
The tokens sat, bank, and river make the river meaning more likely. Self-attention helps the model pull those clues into the representation of bank. After enough layers, the token representation is no longer just “bank.” It becomes something more like:
“bank, in this context, meaning the side of a river.”
Again, not as a human-readable sentence inside the model, but as a numerical representation that carries contextual meaning. Takeaway: Self-attention helps tokens become context-aware instead of being treated as isolated dictionary entries.

Transformer layers refine representations repeatedly

A single attention step is useful, but transformers do not stop there. They stack many layers. A model might have:
  • 24 layers
  • 32 layers
  • 40 layers
  • 80+ layers in larger models
Each layer takes the current token representations and updates them again. A simplified flow looks like this:
plaintext
Token IDs
  ↓
Initial token vectors
  ↓
Layer 1: simple local relationships
  ↓
Layer 2: syntax and phrase patterns
  ↓
Layer 3: broader dependencies
  ↓
...
  ↓
Later layers: richer abstractions and task-relevant patterns
  ↓
Final representation used to predict the next token
Do not take that layer breakdown too literally. It is not guaranteed that layer 1 always does one clean thing and layer 20 always does another clean thing. But as a mental model, it helps:
  • Early layers often capture simpler patterns.
  • Later layers can combine earlier signals into more abstract patterns.
For example, as information moves through layers, the model may refine:
  • Which words modify which other words
  • Which entity a pronoun refers to
  • Whether a sentence is asking a question
  • Whether the user wants code, explanation, summary, or reasoning
  • Which parts of the prompt are instructions versus content
  • Which tokens are most relevant for the next-token prediction
This repeated refinement is why the transformer is powerful. It does not process a sentence once and call it done. It keeps transforming the internal representation.
Takeaway: Transformer layers repeatedly refine token representations, allowing simple token patterns to become richer contextual understanding.

Multi-head attention tracks different relationship types

If a single attention pattern is useful, multiple attention patterns are better. That is the idea behind multi-head attention. A transformer layer does not usually have one attention mechanism. It has multiple attention heads. Each head can learn to focus on different kinds of relationships.
One head might track local grammar.
  • Another might track subject-verb relationships.
  • Another might track repeated names.
  • Another might track formatting patterns.
  • Another might track instruction boundaries.
  • Another might track relationships between code symbols.
  • This is a simplified explanation, but it captures the purpose.
Multi-head attention lets the model analyze the sequence from multiple angles at once. Example prompt:
Sarah gave Anna her notebook because she trusted her.
There are several relationships to track:
  • Who gave something?
  • Who received it?
  • What was given?
  • Who trusted whom?
  • What does each her refer to?
  • What does she refer to?
A single attention pattern may not capture all of this cleanly.
Multiple heads give the model more ways to represent competing or overlapping relationships.
Takeaway: Multi-head attention lets the model track different relationship patterns in parallel.

Self-attention does not mean perfect understanding

Attention is powerful, but it is not magic. It does not guarantee that the model truly “understands” the way a person does. It also does not guarantee correct answers. The model is still doing next-token prediction using learned weights and current context. Self-attention helps it use context better, but errors can still happen. A model may:
  • Attend to the wrong part of the prompt
  • Overweight irrelevant context
  • Miss a subtle constraint
  • Confuse similar entities
  • Follow misleading patterns from training
  • Produce a plausible answer that is still wrong
This is especially important for local LLMs. Smaller local models may have fewer layers, fewer attention heads, less training data, or weaker instruction tuning than frontier hosted models. That does not make them useless. It means you should understand their limits. A 7B or 8B local model can be excellent for many tasks, but it has less representational capacity than a much larger model.
Takeaway: Self-attention improves contextual reasoning, but it does not make the model infallible.

Why self-attention matters for local LLMs

When you run a local model, all of this is happening on your machine. The runtime loads the model. Your prompt becomes tokens. Those tokens become vectors. The vectors pass through many transformer layers. Each layer applies attention and other transformations. The final representation is used to predict the next token. Then the process repeats. This is why local inference has real hardware costs. Longer context means more tokens need to participate in attention. More layers means more repeated transformations. More parameters means more learned weights to load and compute through. Larger models may produce better outputs, but they also demand more memory bandwidth, more RAM or VRAM, and more compute. This connects directly to everything we have already covered:
  • Tokens define the sequence.
  • The context window defines how much active text the model can use.
  • Weights define the learned transformations.
  • Softmax and sampling choose the next token.
  • KV cache speeds up repeated generation.
  • Transformer layers and attention are the engine doing the contextual processing.
Takeaway: Self-attention is not an abstract research concept. It is part of the actual computation your local machine performs every time a model generates text.

Save-worthy framework: The 5-step attention mental model

When you see “self-attention,” remember this:
plaintext
1. Each token starts as a vector.
2. Each token compares itself with other tokens.
3. Attention weights decide which tokens matter more.
4. The token representation gets updated with context.
5. Stacked layers repeat this until the model can predict the next token.
Or even shorter:
plaintext
Token meaning is not fixed.
Attention makes token meaning contextual.
Layers make context progressively richer.
That is the core idea. Takeaway: A transformer does not just read tokens. It repeatedly rebuilds what each token means based on the surrounding sequence.

A simple diagram

Here is the basic flow:

You do not need to memorize every subcomponent yet. For this article, the important part is:
plaintext
Self-attention lets tokens exchange context.
Layers refine that context again and again.

Common mistakes beginners make

Mistake 1: Thinking attention is human focus Attention is inspired by the idea of focus, but in a transformer it is a numerical operation. The model is not consciously deciding what matters. It is computing learned relationships between token representations.
Takeaway: Attention is not awareness. It is a learned mechanism for mixing contextual information.
Mistake 2: Thinking each word has one fixed meaning In a transformer, the same token can have different internal representations depending on context. Apple in a fruit recipe and Apple in a stock market article are not treated the same after contextual processing. Takeaway: Token meaning becomes context-dependent as it moves through transformer layers.
Mistake 3: Thinking one layer understands everything Transformers work through repeated refinement. One layer is not the whole model. Each layer updates the sequence, and later layers build on earlier layers. Takeaway: Depth matters because understanding is built through many transformations, not one pass.
Mistake 4: Thinking more context is always better More context gives the model more information, but it also adds more tokens to process. That can slow inference and introduce distractions. A messy long prompt can perform worse than a shorter, clearer one.
Takeaway: Context is useful when it is relevant. More tokens are not automatically better.
Mistake 5: Thinking attention guarantees correct reasoning Attention helps the model connect information, but it does not guarantee truth. The model can still miss constraints, hallucinate, or follow a misleading pattern.
Takeaway: Attention improves contextual processing, but verification still matters.

Practical next step

Take a short sentence with an ambiguous word or pronoun. Example:
The trophy did not fit in the suitcase because it was too small.
Ask yourself:
  • What does it refer to?
  • Which earlier tokens matter most?
  • What would change if “small” became “large”?
  • Which relationships would the model need to track?
Then rewrite the sentence:
The trophy did not fit in the suitcase because it was too large.
Now the likely referent changes. This is a simple way to feel why attention matters. The model needs to connect tokens across the sequence to resolve meaning.
Takeaway: If changing one word changes what another word refers to, self-attention is part of how the model can adapt.

The big picture

So far in Local LLM 101, we have built the pieces:
  • Text becomes tokens.
  • Tokens fit into a context window.
  • Model weights store learned patterns.
  • Inference predicts one token at a time.
  • Sampling turns probabilities into output.
  • KV cache speeds up continuation.
  • Transformers process token sequences.
  • Self-attention lets tokens influence each other.
Now the engine should feel less mysterious. An LLM is not retrieving a prewritten answer. It is transforming a sequence of token representations through many layers, using learned weights and attention patterns, then predicting the next token. That process repeats until the answer is complete. Takeaway: Self-attention is the transformer’s core context mechanism. It lets each token update itself using the rest of the sequence.
