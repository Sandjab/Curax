I spent a week testing Claude Code plugins. Here are 5 that actually worth it
Claude Code is the smartest coding agent on the planet right now.
But it's forgetful, mute, and impulsive.
Every session starts from zero. It doesn't remember what you built yesterday. It can't hear you - you type everything. And when you give it a task, it jumps straight into code without thinking for a second.

Part 1 - Memory

Claude-mem - Claude remembers everything between sessions (38,000+ stars)
github.com/thedotmack/claude-mem
Here's the problem: you spend 2 hours explaining your project to Claude. Architecture decisions. Naming conventions. That weird bug you fixed last Tuesday.
Every morning you open a new session - and Claude has no idea who you are.
claude-mem fixes this permanently. It captures everything Claude does during your sessions, compresses it with AI, and injects relevant context back into future sessions automatically.
python
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
That's it. Restart Claude Code. Context from previous sessions will automatically appear.
What's happening under the hood:
plaintext
SessionStart     → loads relevant memories from past sessions
UserPromptSubmit → captures your requests for context
PostToolUse      → records every tool action and result
Summary          → AI-compresses the session into key insights
SessionEnd       → stores everything for next time
5 lifecycle hooks running in the background. SQLite database at ~/.claude-mem/claude-mem.db. Everything local - your data never leaves your machine.
There's also a web viewer at http://localhost:37777 where you can browse all your sessions, search history, and manage what Claude remembers.
And here's the interesting part - there's a beta feature called "Endless Mode". Biomimetic memory architecture for sessions that go on for hours without context degradation. Switch to beta from the web viewer UI -> Settings.
Result: "Come back to a long-running project after a week off. Claude already knows the architecture decisions you made, the bugs you fixed, and the patterns you established."
Replaces: Re-explaining your project at the start of every session.

Part 2 - Second brain

Obsidian-mind - a vault that organizes itself (180+ stars in first week)
github.com/breferrari/obsidian-mind
Claude-mem gives Claude memory of code sessions. obsidian-mind gives Claude memory of everything else - your work, your people, your decisions, your goals.
You talk. Claude files.
You type: "Just had a 1:1 with Sarah. She's happy with auth , but wants error monitoring before release. Tom said cache migration deferred to Q2."
What Claude does automatically:
plaintext
→ Creates 1:1 note in work/1-1/Sarah 2026-03-26.md
→ Updates person file org/people/Sarah Chen.md
→ Creates Decision Record: "Defer Redis migration to Q2"
→ Adds win to perf/Brag Doc.md
→ Updates active project status
You never organize anything. The vault organizes itself.
Install:
python
git clone https://github.com/breferrari/obsidian-mind.git ~/my-vault
cd ~/my-vault && claude
Say "start session" and Claude reads your North Star goals, checks active projects, scans recent memories, and tells you exactly where you left off.
What makes this different from a normal Obsidian vault:
SessionStart hook - auto-injects your goals, active projects, recent changes, open tasks, and full vault file listing. Claude starts every session with context, not a blank slate.
15 slash commands:
plaintext
/standup  → loads everything for your daily standup
/dump     → quick brain dump, Claude classifies and files it
/wrap-up  → verifies notes, updates indexes, spots uncaptured wins
/review   → prep for performance reviews with evidence trail
9 subagents for heavy operations - each specialized for a different task.
QMD semantic search - find "what did we decide about caching" even if the note is titled "Redis Migration ADR". Install:
python
npm install -g @tobilu/qmd
qmd collection add . --name vault --mask "**/*.md"
qmd update && qmd embed
Replaces: Hours of manual note organization. Performance review panic. "What did we decide about X last month?"

Part 3 - Voice

VoiceMode - talk to Claude like a person
github.com/mbailey/voicemode
You're debugging something cool. Hands on the keyboard. You know exactly what to say but you have to type it character by character.
VoiceMode turns Claude Code into a voice conversation. You speak, Claude listens, processes, and speaks back.
python
# As Claude Code plugin
/plugin marketplace add mbailey/voicemode
/plugin install voicemode

# Install dependencies
/voicemode:install

# Start talking
/voicemode:converse
Speak when you hear the chime. Claude responds with voice in a few seconds.
What's running under the hood:
python
You speak → Microphone
          → Whisper (speech-to-text)
          → Claude Code processes
          → Kokoro (text-to-speech)
          → Speakers → You hear
Works offline - local Whisper for STT, local Kokoro for TTS. No data sent to anyone. Or use OpenAI API as fallback if you prefer cloud.
67 voices
From professional to casual:
plaintext
# Try different voices
claude converse --voice af_sky
claude converse --voice am_adam
claude converse --voice af_heart
For full offline privacy:
plaintext
voicemode service install whisper   # speech-to-text
voicemode service install kokoro    # text-to-speech
voicemode service start whisper
voicemode service start kokoro
~500MB download for Whisper base + Kokoro. After that — completely offline. No API keys needed.
Replaces: Typing when you should be talking. $20/month for
Otter.ai
or similar transcription tools.

Part 4 - Discipline

Superpowers - Claude thinks before it codes (obra)
github.com/obra/superpowers
Here's what Claude does without Superpowers: you say "build me a dashboard" - it immediately writes 400 lines of code. No clear plan, no consideration of existing patterns, no tests. Just code.
Superpowers forces Claude to stop and think.
python
/plugin marketplace add obra/superpowers
/plugin install superpowers
What changes after installing:
  • TDD mode - Claude writes tests before writing implementation. Not after. Before.
  • Brainstorming - Claude explores multiple approaches before committing to one.
  • Debugging - Structured root cause analysis instead of random fixes.
  • Skill authoring - Claude creates reusable skills from patterns it discovers.
A real user on DEV Community who tested it for 3 months: "Discovering Superpowers in late November fundamentally changed how I work."
The difference is very simple. Without Superpowers, Claude produces code. With Superpowers - solutions. Code that has tests, fits the architecture, and doesn't break things.
Replaces: Manually telling Claude "think first, then code" every single time. Code that works today and breaks tomorrow.

Part 5 - Strategy

Compound Engineering - every unit of work makes the next one easier (EveryInc)
github.com/EveryInc/compound-engineering-plugin
Superpowers makes Claude think before coding. Compound Engineering makes Claude think before everything.
The philosophy: "Each unit of engineering work should make subsequent units easier - not harder. Traditional development accumulates technical debt. Compound engineering inverts this."
python
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
The workflow:
plaintext
/ce:brainstorm → refine ideas through interactive Q&A
/ce:plan       → distill into technical plan grounded in repo patterns
/ce:work       → execute with automatic confidence checking
/ce:review     → catch issues before they compound
/ce:compound   → extract patterns for future use
80% is in planning and review. 20% is in execution.
/ce:plan is the key command.
It doesn't just plan - it launches multiple research agents in parallel. One reads your codebase. Another checks patterns. Another finds confidence gaps. The result is a plan.md that agents (or humans) can actually work from.
One user's real numbers: 70 plan files and 263 commits in the last 30 days. His rule: "Unless it's literally a one-line change, there's a plan.md first. Always."
/ce:ideate is the hidden gem - it proactively surfaces improvement ideas based on your codebase. You don't ask for ideas. Claude finds them.
Works with Claude Code, Codex, Gemini CLI, GitHub Copilot, Windsurf, OpenCode, and 5 more tools. One plugin, 11 platforms.
Replaces: The "just start coding and figure it out" approach that creates technical debt. Spending more time fixing old code than writing new features.
