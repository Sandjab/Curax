Hack #5: Claude Skills 2.0

Claude Skills 2.0
The new Claude Skills update just went over 99% of people's heads.
Anthropic just shipped a massive new update to Claude Skills.
You can now:
  • Edit/evaluate Claude skills in real-time
  • Create more effective skills in a fraction of the time
  • Test Skills before deploying them
and much more.
If you haven't tested the new Claude Skills, you need to.
Getting Started with Claude Skills
You don't need to build and manually import skills anymore; you can just ask Claude to create one for you and copy it to your account.
Here's the prompt I use to build a new skill from scratch:
PROMPT

"I want to build a Claude skill for [task name]. Here is exactly how I want it to behave: [describe the behavior]. These are the questions I want it to ask me before producing an output: [list your questions]. This is the format I want the output in: [describe the format]. These are the constraints: [list any constraints]. Build me a complete skill file I can save and use with a slash command."
Claude builds the skill, you save it to your account, and from that point forward, you just type the slash command to activate your skill.
Skills to Build First
Here is a sample of a few skills I'd build immediately if I were starting from scratch:
  • /tweet-writer: Generates tweet variations in your voice from a rough idea (or any content drafts aside from tweets)
  • /meeting-prep: Prepares a structured brief before any meeting
  • /research-report: Produces a structured research summary on any topic
  • /weekly-review: Runs a structured review of your week and flags priorities for the next one
Each of these replaces a recurring manual workflow. Stack them, and you've automated hours of weekly work before you've touched anything else in this article.
If you haven't tested Skills, the new 2.0 Skills update is the highest leverage thing you can do with Claude right now.

Hack #4: Claude Dispatch

Claude Dispatch
I honestly can't believe more people aren't talking about this.
A few months ago, Anthropic released a feature that allows you to gain remote control access to your Claude desktop.
This means you can prompt Claude on the go from your phone and get it to access all your desktop tools.
Getting started with Claude Dispatch
  1. Open the Claude Desktop app and navigate to Dispatch.
  2. On your phone, open the Claude mobile app and click "Pair with your desktop."
  3. Follow the pairing prompts. Once connected, select "Let Claude control my computer" and update your accessibility settings to allow it.
  4. Optional but recommended: enable "Keep computer awake when Dispatch is running" so tasks complete even when your screen is off.
Setup takes under five minutes, and once it's done, it's done forever.
This is the easiest way to turn Claude into your personal assistant.
Real Dispatch prompts to test:
Desktop + File Access
"Go into my downloads folder and organise every file by category. Create a folder for each category and move everything into the right place. Rename anything with a meaningless file name."
"Read all the notes in my documents folder and create a single summary markdown file called weekly-context.md that captures the key information across all of them."
"Find every file I haven't opened in the last 30 days and move them into an archive folder."
Instant Research for Any Topic
"Research the latest news on [topic] and write a structured briefing document. Save it to my research folder so it's ready when I get back to my desk."
"I have a meeting with [person] in two hours. Look them up, read any files I have on them in my contacts folder, and create a meeting prep brief. Save it to my desktop."
Daily Update Prompt (before bed)
"Go through everything I worked on today in my files and update my memory file with anything important. Flag anything that still needs to be done tomorrow."
A complete game-changer for using Claude on the go.

Hack #3: Claude Code but NOT for Coding

Most people hear "Claude Code" and immediately think it's only for developers - that couldn't be further from the truth.
Claude Code is a general-purpose agent that lives on your machine. Yes, it can write code, but that's only half of what it's actually useful for.
The real power in Claude Code is using it to access your local desktop data for daily productivity (most of us aren't developers).
The Real Power of Claude Code: A Personal Memory System
The most powerful thing you can build inside Claude Code is a personal memory system.
A structured folder system on your computer that Claude uses to give you dramatically more relevant and accurate outputs.
It's like a second-brain memory database (you can also transfer this memory to other LLMs/AI tools).
Here's how to set it up:
Step 1: Create your memory folder
Create a folder on your computer called something like "Claude Memory" or "Personal OS" - this is where your entire architecture will live.
Step 2: Build your core files
Inside that folder, create two essential files:
  • identity.md: Who you are, what you do, your goals, your preferences, your communication style, your business context. Everything Claude needs to understand you.
  • memory.md: A running log of important decisions, ongoing projects, key context, and anything noteworthy that comes up in your work.
Step 3: Add a key instruction
At the top of your identity.md file, add this line:
INSTRUCTION
"At the start of every session read memory.md and identity.md for context on past work and preferences. Update memory.md whenever something noteworthy comes up in our conversation."
Step 4: Connect Claude Code to your folder
Every time you open Claude Code/Cowork, select this folder.
Claude will read both files automatically and gain full context before you type a single word.
You can use this as a general memory system or replicate it for specific projects.
From that point forward, Claude knows who you are, what you're working on, and how you like things done. And it updates its own memory as you work.
This is just one example of how you can leverage the full capabilities of Claude Code for daily productivity.
TLDR: start using Claude Code for more than just coding.

Hack #2: Claude-Ception

This one is hard to explain without showing you, but once you see it, you'll wonder why you've been using Claude any other way.
Most people interact with Claude through the chat interface - you send a text, and it responds back with text.
That works fine for simple tasks - but for anything visual, repetitive, or multi-output, there's a better way.
"Claude-ception" is the idea of building a custom AI-powered interface inside Claude, using Claude.
Instead of asking Claude to write five tweet variations in a chat and reading them in a block of text, you could build a "Tweet Riff Machine" where you paste a rough idea, hit a button, and get five polished variations displayed side by side in a clean visual layout.

Essentially, you're creating live artifacts inside of Claude that allow you to interact with Claude in a more visual way instead of the normal chatbox.
Super useful for HTML files, comparing outputs side-by-side, or just interacting with Claude in a more visually appealing format.
Pro tip: You could even pair this up with Claude Skills.

Hack #1: Sub-agents

This is a hack for all the power users.
Instead of using just one Claude at a time, you can spin up multiple sub-agents inside of Claude Code.
For example, you can deploy:
  • A dedicated research agent
  • A dedicated coding agent
  • A dedicated content agent (writes tweets, articles, etc.)
  • An agent that oversees all the others for quality control
Here's a simple Claude Code prompt you can use to spawn multiple sub-agents in parallel:
PROMPT
"Spawn four sub agents in parallel. Agent one: research the latest news on [topic]. Agent two: draft a 500 word newsletter based on that research. Agent three: write five tweet variations. Agent four: build a quick HTML landing page mockup about it. Report back when all four are complete."
The real unlock is training these agents with specific skills so they know how you like to work.
I like to use .md files and upload them to a dedicated folder for each agent to make them easier to read.
Once you start using this workflow, you'll never go back - using sub-agents is a huge Claude life hack.
