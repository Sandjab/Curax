11 Claude things I wish someone had told me 12 months ago
I thought AI got powerful when I learned prompting.
I was wrong.
It got powerful when I stopped treating it like a chatbot.
Most people still use Claude like: → smarter autocomplete → faster Google → prompt machine
But the people getting insane results?
They’re building systems around it.
And after reading hundreds of discussions from heavy daily users…
these 11 patterns showed up again and again:
  1. Projects are massively underrated
Most people start every chat from zero.
Bad move.
The best users dump: → codebase context → style guides → docs → architecture decisions → old PRs
inside Projects once…
and stop re-explaining themselves forever.
One person said they wasted 100+ hours before realizing this.
That’s probably common.
  1. Your CLAUDE.md matters more than your prompts
This came up constantly.
A good CLAUDE.md becomes the “operating manual” for the AI.
Tech stack. Commands. Rules. Architecture. Sharp edges. Coding conventions.
The AI stops guessing.
And honestly?
Most prompting problems are actually context problems.
  1. Custom styles are a cheat code
One idea absolutely blew up:
A custom style called: “skeptical senior engineer”
Instead of agreeing with everything…
it pushes back. Questions assumptions. Finds flaws. Acts like a harsh reviewer.
That alone massively improves output quality.
Because AI’s biggest weakness is fake confidence.
  1. Sonnet should probably be your default
A lot of advanced users reached the same conclusion:
Sonnet handles ~80% of work perfectly.
People waste insane amounts of usage forcing Opus onto simple tasks.
The emerging stack looks like:
Haiku: → summaries → repetitive tasks → cleanup
Sonnet: → daily driver → writing → coding
Opus: → architecture → deep reasoning → huge context tasks
Model routing is becoming a real skill.
  1. Haiku is WAY more useful than people think
People underestimate small models.
But for: → support tickets → extraction → categorization → email drafting → PDF summaries
Haiku is ridiculously efficient.
You don’t need Ferrari horsepower for grocery runs.
  1. Voice mode changes how you think
This one surprised me.
A lot of people use voice mode while: → walking → driving → brainstorming
Not because it’s perfect.
Because it unlocks a different thinking style.
Some users literally solve better problems while moving.
That’s fascinating.
  1. Subagents quietly change everything
This is where things get crazy.
Example workflow:
“Spin up a subagent to run tests while I keep coding.”
That sounds small.
But it fundamentally changes the interaction model.
It’s no longer: human ↔ AI
It becomes: human ↔ AI workforce
That shift is HUGE.
  1. Skills > giant prompts
People are moving away from mega-prompts.
Instead they build reusable workflows.
Things like: → automatic doc retrieval → repo auditing → file-specific behavior → structured task execution
The best setups reduce ambiguity as much as possible.
One user said:
“Make workflows deterministic. Don’t rely on prose.”
That’s an important insight.
  1. Memory is both powerful and weird
A lot of users got freaked out when Claude started referencing old conversations.
Because memory fundamentally changes the feel of the product.
The AI stops feeling stateless.
And suddenly continuity becomes part of the workflow.
That changes user behavior completely.
  1. Most AI users still massively overtrust outputs
This point came up repeatedly.
Experienced users don’t just read outputs anymore.
They inspect: → traces → actual execution → generated files → commits → actions taken
Because polished language ≠ correctness.
And honestly…
AI sounding confident is still one of the biggest traps.
  1. The future is systems, not prompts
This was the real theme underneath every discussion.
The biggest gains aren’t coming from: “better prompts.”
They’re coming from: → persistent memory → reusable context → workflow orchestration → specialized behaviors → parallel agents → connected tools
The smartest users are no longer “talking to AI.”
They’re designing environments AI operates inside.
That’s the actual shift happening right now.
And most people haven’t noticed it yet.
Based on conversations and workflows shared by advanced Claude users.
