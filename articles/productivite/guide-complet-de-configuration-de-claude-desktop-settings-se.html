Don't Start Using Claude Until You've Set It Up Right. Here's My Complete Setup Guide.
Claude Desktop ships with 28+ configurable settings. Most users touch three of them. The gap between the minimum-viable setup and a workstation that actually works is about 20 minutes of toggles. Once you’ve done it, Claude stops feeling like a chat app. It starts feeling like an operating system. Quick context before we start. Claude Desktop is no longer just a chat app. It ships with three separate workspaces in one download: Chat (the classic conversation), Cowork (Claude driving your computer or browser for you), and Code (a full development environment). The rest of this guide assumes you get the shape of what Claude Desktop is now.
Here’s the full setup, section by section, in the order it appears in the Settings panel.

Profile

This is your get-to-know-you layer. Three things worth configuring here.
What should Claude call you. Use your preferred name. Claude uses it across every conversation. Simple but often skipped.
Personal preferences. Anthropic published
a guide on personalization
worth reading before you start. But honestly… I leave this blank. Sometimes too much context can be counterproductive, and I believe this is where Claude’s built up memory is more productive. If you do fill this out, be direct and concise, and only add context that will add value for Claude. (Don’t write a novel). Notifications. Desktop and dock notifications for things like “Claude is done with that long task.” Turn it on. The alternative is staring at your screen waiting.

Usage

Your limits dashboard. Every Claude plan has a usage cap within a given window (every five hours for most plans). You’ll see your current usage, your reset timer, and whether you’re anywhere close to the ceiling.
One toggle here matters: extra usage. Turn it on if you want Claude to keep working when you hit the limit. Overage gets billed separately (pay-as-you-go). For anyone actually using Claude for work, it’s a fair trade. Hitting a limit mid-task and waiting four hours for the reset is a bigger problem than a few dollars in overage.
(Counterpoint: if you’re on a tight budget or using Claude casually, leave it off. The included limits reset plenty for light use.)
A note on model choice if you’re watching your usage. Anthropic’s newest model, Opus 4.7, is a token hog. It’s the most powerful thing in the lineup and the right tool for your hardest problems, but it burns through usage fast. If you’re on a plan where that matters, keep Sonnet 4.6 as your daily driver and reserve Opus 4.7 for the tasks that actually need it (deep research, complex analysis, long-running agent work). Capabilities

The real leverage of the settings panel. capabilities.
1. Memory (turn both toggles on)
The first toggle is Search and reference chats. It lets Claude look up relevant past conversations when you’re in a new one. Turn it on.
The second toggle is the one that matters: Generate memory from chat history. With this on, Claude continuously distills what it learns about you across every conversation into a single memory document it can reference. Work context, projects you’re building, preferences, frequent collaborators. All of it compounds. I don’t re-explain myself. Claude already knows.
One feature most people miss: the Import memory from other AI providers button. If you’ve been on ChatGPT for a year and built up a ton of context there, Claude will pull that memory over in one click. Sign into your other account, Claude fetches the memory data, and your new Claude conversations start pre-loaded with what your old AI knew about you. If you’re transitioning tools, this is a genuinely useful shortcut. No one should start from zero.
Two more memory surfaces worth knowing about:
  • Projects in Claude Chat and Cowork have their own isolated memory. When you create a Project (a dedicated workspace for a specific initiative, like a client, a product, or a book), configure memory once at the project level and everything inside that Project inherits the context. Use Projects to keep your client work separate from your internal work separate from your side projects. Each Project’s memory is configured at the project level, not globally.
  • Claude Code’s CLAUDE.md file is effectively Claude’s memory for a codebase. Paired with your actual code, it’s how Claude remembers what the project is, what conventions it follows, and what you’ve decided along the way. Keep it updated. I’ve written mine by hand for some projects and had Claude maintain it for others. Both work.
2. Tool Access
Two options: “Load tools when needed” or “Tools already loaded.” Pick Load tools when needed. It keeps Claude from burning context space on tools you’re not using in the current conversation. Your chats compact less often. Claude stays sharper. The always-loaded option is a holdover from older versions. Modern Claude figures it out.
3. Visuals
Three toggles here: Artifacts, AI-powered artifacts, and inline visualizations. Turn all three on. These are free capability upgrades.
  • Artifacts lets Claude produce full HTML, React, and interactive outputs in a side panel you can copy or export.
  • AI-powered artifacts means Claude can call its own API from inside an artifact to do something dynamic, like a working mini-app.
4. Code Execution and File Creation
Cloud code execution and file creation: on. This is what lets Claude actually build the .pptx, the .xlsx, the .pdf, the data report. Required for skills. Non-negotiable if you want Claude producing actual deliverables and not just describing them.
Allow network egress: on, with the domain allowlist set to Package managers only. That lets Claude’s sandboxed environment install the packages and libraries it needs for advanced work (custom visualizations, specialized file processing, data analysis) without opening the door to arbitrary internet traffic. Add specific domains to the allowlist only when you have a clear reason.

Connectors

This is the settings panel that turns Claude from a chatbot into an agent.
Read that sentence again. Connectors are the single biggest leap in what Claude can do for you, and most users I talk to haven’t flipped on half of them. Without Connectors, Claude is a very smart writing assistant that knows nothing about your actual world. With Connectors, Claude can read your calendar, triage your inbox, check your Slack for things you’ve missed, pull deal movement out of your CRM, summarize what’s pending in Notion, and then go act on all of it for you.
That shift, from answering questions to doing your work, is the one people mean when they say “AI is changing everything.” It does not happen in the chat window. It happens in this settings panel. If you do nothing else in Settings today, come back and turn on every Connector you live in.
Connectors are one-click integrations that let Claude read (and often write to) the tools you already use. Gmail. Google Calendar. Google Drive. Slack. Notion. HubSpot. Linear. GitHub. The catalog is long and growing every week.
How to connect one. Click the tool you want, authorize it with your account, Claude can now use it. A few seconds per tool.
What to connect. Every tool you actually live in. Every one you leave disconnected is a tool Claude can’t see into, which means every agent you build will be blind on that surface. If you’ve built any kind of workflow in Claude (a daily briefing, a sales triage agent, a BD researcher), Connectors are the wiring that makes it all work. My Executive Assistant agent pulls from Calendar, Gmail, Slack, HubSpot, Notion, and Granola every single morning. Zero Connectors, zero brief.
Custom connectors. If your company runs an internal tool with an API, there’s also an option to add a custom connector. Deeper rabbit hole, but the door is open. If your IT team has an MCP-compatible endpoint, you or an engineer can wire it up in an afternoon. That’s how you get Claude talking to the systems that matter most inside your business.

Claude Code

Claude Code is the full dev environment inside Claude Desktop. Even if you’re not a developer, two toggles here are worth knowing about.
Allow auto permissions mode: turn this on. Without it, every single time Claude wants to take an action (edit a file, run a command, open a tab), it stops and asks. For short tasks, that’s fine. For anything that runs more than a few minutes, it’s death by a thousand prompts. Auto mode lets Claude handle routine permission decisions itself, with built-in safeguards against prompt injection, so you can kick off real work and walk away. This is the single most impactful Claude Code setting for non-developers.
Allow bypass permissions mode: this one skips permissions entirely. No prompts, no confirmation, Claude does whatever it thinks is right. The risk is real. A bad prompt or a prompt-injection attack can cause actual damage (files modified, data exfiltrated, commands executed). Anthropic labels this clearly and they’re right to. My honest take: if you’re not reading the prompts anyway (and most casual users aren’t), turning this on is effectively the same thing as auto-approving every one. Either engage with the prompts or skip them consciously. The worst outcome is pretending to read them when you’re not.
A few other settings worth a glance in this section but not urgent: Worktree location, Branch prefix, Preview, Persist Preview sessions. These matter mostly for developers running live previews and isolated coding sessions. Leave the defaults if the words don’t mean anything to you.
Claude Code on the Web. If you use Claude Code against a GitHub repo, the “Create pull requests automatically” toggle means Claude will push and open a PR without asking first. Turn on “Create as draft” underneath it so you get a review window before merging. “Autofix pull requests” lets Claude respond to CI failures and review comments on its own. Powerful if your CI is good, dangerous if it isn’t.

Cowork

Cowork is the workspace where Claude drives a computer, a browser, or an app for you. If you’ve seen demos of Claude opening tabs, filling out forms, and clicking through an interface on its own, that’s Cowork.
The setting to enable: Dispatch. It lets Cowork kick off background tasks that run independently of your active chat. Long-running research. Multi-step workflows. Anything you want happening while you’re doing something else. Without Dispatch, Cowork is live-only. With it, Cowork becomes more like a worker you can assign tasks to and walk away from.
Here’s the part most people miss. With Dispatch on, you can keep giving Claude commands from your phone while the task runs. Kick off a research job on your laptop, leave for lunch, and add follow-up instructions from the Claude mobile app as new questions come up. Check back when you’re ready. It’s async Claude. Once you’ve used it for a real workflow, you do not go back.

Claude in Chrome

This is the bonus tip from the video. Genuinely underrated.
Claude in Chrome is a browser extension that gives Claude the ability to use your browser directly. Click buttons. Fill forms. Navigate between tabs. Extract data from pages. The practical effect: you can ask Claude to do something a person would do in a web app, and watch it happen.
How to enable it. In Settings → Claude in Chrome, toggle it on. Install the extension from the Chrome Web Store. Pin it to your toolbar. Done.
Where it earns its keep. Research across a dozen tabs. Bulk-filling forms from a spreadsheet. Pulling information from a tool that doesn’t have a Connector. Testing a web app by having Claude click through it. It’s what AI agents look like when they’re actually embodied in a place you can watch them work.

Desktop App (General, Extensions, Developer)

Last stretch, but don’t skim. The General section alone has five settings that change how Claude integrates with the rest of your machine, plus a Browser Use and Computer Use block that most users have never opened.
General desktop settings
  • Run on startup. On. Launches Claude automatically when you log in. Table stakes if you want scheduled tasks running without you manually opening the app each morning.
  • Quick access shortcut. Defaults to “Tap Option twice.” Summons Claude from anywhere on your desktop, no matter what app you’re in. Faster than Cmd-Tabbing. Worth pinning muscle memory to. Customize the shortcut if the default conflicts with something else you use.
  • Voice shortcut. Defaults to Caps Lock. Press once to start dictating, press again to stop. Underrated input mode, especially for long context dumps or when you’re thinking out loud. I use it when I’m walking and need to get an idea into Claude before I lose it.
  • Menu bar. On. Keeps Claude’s icon in your menu bar for one-click access from anywhere on your machine.
  • Keep computer awake. This one matters more than it sounds like. With it off (the default), your computer can sleep and your scheduled tasks will not run. Turn it on if you want the Executive Assistant brief waiting for you at 7am every day, including the days you forget to open the laptop. Your display still turns off. Just the idle-sleep gets paused.
Browser Use
Allow all browser actions. On if you’re comfortable with Claude interacting with any website in Chrome without asking first. More powerful for agent workflows, but Anthropic attaches a clear risk note and they are right to. For most users, the default (ask per session) is the safer starting point. If you’re running heavy Chrome-based agent work and the permission prompts are killing your flow, turn it on consciously.
Computer Use (Beta)
This is the OS-level capability that lets Cowork actually drive your desktop. Turning it on enables Claude to take screenshots and control your keyboard and mouse in the apps you explicitly allow. Four things to know here.
  • Enable Computer Use. Toggle it on if you want Cowork to automate anything on your actual machine. Without it, Cowork is limited to the browser. With it, Cowork can operate native desktop apps.
  • Unhide apps when Claude finishes. On. Returns any apps that got hidden during a task back to visible when the task ends.
  • Denied apps. A safety list. Add any app you absolutely do not want Claude touching. Password managers. Finance tools. Your HR system. Anything with sensitive data or irreversible actions. Denied apps stay denied even if Claude is otherwise authorized. This is where you draw your real line.
  • Accessibility. The macOS permission Claude needs to control your computer. Grant it once. Required for Computer Use to work at all.
Extensions
A catalog of optional add-ons that extend Claude Desktop’s capabilities. Worth browsing occasionally. New ones ship regularly.
Developer
Ignore this unless you’re building against Claude’s APIs or debugging an agent. It’s there for power users and the curious. If you don’t know what it’s for, you don’t need it.

If You Do Nothing Else

The four moves that earn their 20 minutes back in the first week:
  1. Memory on. Both toggles. Import your ChatGPT history if you have one.
  2. Every Connector you use, connected. Gmail, Calendar, Slack, your CRM, your docs tool.
  3. Auto permissions mode on in Claude Code. The difference between short tasks and real work.
  4. Claude in Chrome installed. The bonus that keeps surprising people.
Everything else is optional tuning. These four are the floor.

What To Do This Week

  1. Today. Open Claude Desktop, go through Settings top to bottom, toggle the four moves above. Fifteen to twenty minutes.
  2. Tomorrow. Spend ten minutes on your Profile and personal preferences. Be specific. Every conversation after that compounds.
  3. Later this week. Connect every tool you actually use. Don’t skip any. Claude is only as smart as the data it can reach.
  4. Sometime this month. Go back into Settings and see what’s new. Anthropic ships every week. The list of settings in your Claude Desktop today is not the list you’ll have in 60 days.
Come back to Settings regularly. It’s where Claude gets smarter without you doing anything.
