🧠 08. Claude-Specific (If you use Claude, this is non-negotiable)
Superpowers for Claude
https://github.com/obra-ai/superpowers
Adds serious capabilities to Claude Code—deep repo understanding, auto-refactors, large-scale edits. Think of it as unlocking “real dev mode” for Claude.
Claude Code Skills
https://github.com/anthropics/claude-code-skills
Official system for teaching Claude structured behaviors via skill.md. This is how you make Claude reliable on complex workflows.
Free Claude Code
https://github.com/Alishahryar1/free-claude-code
Run Claude Code via GitHub Models—no subscription. Setup scripts + guides included.
Claude Mem
https://github.com/thedotmack/claude-mem
Adds long-term memory to Claude. Tracks context across sessions—huge for ongoing projects.

🧹 09. Data Prep (The most underrated layer)

Most AI apps fail here.
Not because of bad models— but because of bad data input.
Fix this, and everything improves.
Unstructured
https://github.com/Unstructured-IO/unstructured
Parses PDFs, emails, HTML, images into clean chunks for RAG. This is the missing layer in most pipelines.
DataTrove
https://github.com/huggingface/datatrove
Process massive datasets—deduplication, filtering, classification. This is what serious labs use before training.
Trafilatura
https://github.com/adbar/trafilatura
Extracts clean content from web pages—no ads, no noise. Perfect for feeding high-quality text to models.
